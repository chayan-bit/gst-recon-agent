SGLang

Multi-LoRA serving

One server, one base model, three models: base, base:sft and base:perdoc. The model switcher in this demo is a per-request choice, not a restart.

SGLang + XGrammar

Constrained decoding

The output JSON schema is passed as response_format and compiled to a grammar, so every answer parses and validates against the schema.

AlignTune, our contribution

SGLang rollout backend for GRPO

Rollouts come from a live SGLang server, prompts are sent once with n samples, and weights are synced after each step.
